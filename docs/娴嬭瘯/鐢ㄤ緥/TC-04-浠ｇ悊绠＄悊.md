# TC-04 代理管理

> 覆盖：代理 CRUD、选项、即时探测、已存测试、批量导入、健康检查（SOCKS5+出口归属）、属主隔离、敏感字段保护、管理侧。
> 关联接口：`/proxy/*`、`/admin/proxies/*`；关联文档《产品功能清单》§3.7。

## 探测/测试两条路径

```mermaid
flowchart LR
    F[表单填写主机/端口/账号] -->|不落库| P["/proxy/probe 即时探测"]
    L[已保存代理] -->|写回状态/延迟/出口IP| T["/proxy/:id/test"]
    P --> R[(SOCKS5 实连 + ipvibe 识别归属)]
    T --> R
    R --> O[status/latency/egress_ip/country/city/asn/company/conn_type]
```
