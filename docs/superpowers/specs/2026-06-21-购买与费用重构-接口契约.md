# 购买与费用重构 · 接口契约（前后端并行的冻结契约）

> 配合设计文档 `2026-06-21-购买与费用重构-design.md`。本契约冻结 REST 端点与 JSON 形状，
> 让后端实现与前端联调互不阻塞。金额一律 **cents（分，int64）**；时间一律 **RFC3339 字符串**。
> bps 折扣：10000=全价无折扣，8500=8.5折。kind ∈ {`seat`,`boot_slot`}。

## 0. 路由前缀与鉴权（沿用现状）

- 用户端：billing 模块 `router.Group("/billing")` + `user.AuthMiddleware()`（即前台令牌）。
- 后台：`router.Group("/admin/billing")` + staff 令牌 + `staff.PermissionMiddleware("billing:view"/"billing:manage")`。
- 前端 api client 沿用现有 `my/src/api/modules/billing.ts`、`admin/src/api/modules/billing.ts` 写法。

### 1.3 报价（服务端权威计价）
`POST /billing/quote`
```json
// seat/boot_slot 新购或续费：
{ "biz_type": "seat_new", "quantity": 10, "duration_value": 12 }
// runtime_pack：
{ "biz_type": "runtime_pack", "minutes": 600 }
```
→
```json
{ "quantity": 10, "duration_value": 12, "unit_price_cents": 3000, "billing_units": 120,
  "original_cents": 360000, "qty_discount_bps": 9000, "duration_discount_bps": 7000, "payable_cents": 226800 }
```
`biz_type` ∈ {`seat_new`,`seat_renew`,`boot_slot_new`,`boot_slot_renew`,`runtime_pack`}。续费时报价同样按 quantity（选中单元数）享数量阶梯。

### 1.4 授权单元列表（续费 tab 用）
`GET /billing/license-units?kind=seat&expiring_before=&keyword=` →
```json
{ "items": [ { "id": 101, "kind": "seat", "created_at": "...", "expire_at": "...",
              "instance": { "cp_id": "cp-x", "name": "手机A", "status": "RUNNING" } } ] }
```
`instance` 可为 null（空闲单元）。`keyword` 搜索实例名/标签，`expiring_before` 过滤到期时间。

### 1.5 订单
- `POST /billing/orders` 创建订单（含 recharge）
```json
{ "biz_type": "seat_new", "quantity": 10, "duration_value": 12, "pay_method": "balance" }
// seat_renew/boot_slot_renew 追加: "unit_ids": [101,102]
// runtime_pack: "minutes": 600
// recharge: { "biz_type":"recharge", "amount_cents":10000, "pay_method":"wechat" }
```
→ `{ "order": { ...Order }, "pay": { "status": "paid" } }`（余额支付即时 paid；第三方返回待支付 + 支付参数 stub）。
- `GET /billing/orders?status=&page=&size=` → `{ "items": [Order], "total": n }`
- `GET /billing/orders/:id` → `{ ...Order, "items": [OrderItem] }`
- `POST /billing/orders/:id/pay` 继续支付未支付订单 → 同创建的 pay 结构。

**Order** 形状：
```json
{ "id": 9001, "biz_type": "seat_new", "status": "paid", "total_cents": 226800,
  "pay_method": "balance", "created_at": "...", "paid_at": "...", "expired_at": null }
```
`status` ∈ {`unpaid`,`paid`,`expired`}。

### 1.6 费用日志（聚合到开机会话）
`GET /billing/runtime/log?page=&size=` →
```json
{ "items": [
   { "cp_id": "cp-b", "instance_name": "手机B", "power_on_at": "...", "power_off_at": null,
     "quota_type": "temp", "temp_minutes_charged": 45, "running": true,
     "segments": [ { "quota_type": "boot_slot", "minutes": 0, "from": "...", "to": "..." },
                   { "quota_type": "temp", "minutes": 45, "from": "...", "to": "..." } ] } ],
  "total": n, "daily_cap_minutes": 200 }
```
`quota_type` ∈ {`boot_slot`,`temp`,`capped_free`,`mixed`}。

## 2. 后台（admin/）端点

- 定价：`GET/PUT /admin/billing/pricing`（按 kind：unit_price_cents、qty_tiers、duration_options、notice、billing_note）。
- 临时时长：`GET/PUT /admin/billing/runtime-config`（unit_price_cents_per_minute、packs、min_minutes、daily_cap_minutes、recycle_retention_days）。
- 支付方式：`GET/PUT /admin/billing/payment-methods`（code、name、enabled、sort）。
- 充值预设：`GET/PUT /admin/billing/recharge-presets`（presets_cents[]）。
- 须知文案：`GET/PUT /admin/billing/notices`（按 kind 的 notice/billing_note，及 runtime_pack notice）。
- 订单：`GET /admin/billing/orders?userId=&status=&page=&size=`、`POST /admin/billing/orders/:id/mark-paid`。
- 账户：`GET /admin/billing/accounts/:userId`（余额+流水+各类容量）、`POST .../adjust`（余额增减，理由必填）、`POST .../adjust-resource`（赠送 seat/boot_slot/runtime_minute，走 source=grant）。
- 试用：沿用现有 `GET/POST/PUT/DELETE /admin/billing/trials*` 与 eligibility/grants，subject 收敛为 seat/boot_slot/runtime_minute。

## 3. 跨模块门面（billing 公开包，供 phone 调用）

后端 Agent 负责在 `modules/billing/billing.go` 暴露并保持稳定签名：
```go
// 容量
func SeatCapacity(userID int) (int, error)        // 未过期 seat 单元数
func BootSlotCapacity(userID int) (int, error)    // 未过期 boot_slot 单元数
func RuntimeMinutesRemaining(userID int) (int64, error)
// 席位池 reconcile：传入用户全部非回收实例，返回需进回收站的 cpId（最新溢出）
type InstanceRef struct { CpID string; CreatedAt time.Time }
func ReconcileSeats(userID int, instances []InstanceRef) (recycle []string, err error)
// 开机前置校验：有空闲包月名额或临时时长>0 才允许
func CanBoot(userID int) (bool, error)
// 运行结算（每分钟 tick，phone 编排调用）：满1分钟取整/包月优先/200封顶
func SettleRuntime(userID int, windowEnd time.Time, intervals []RuntimeInterval) (SettleResult, error)
// 实例被删除/回收时释放其在 seat 单元上的占用
func ReleaseInstanceOccupancy(userID int, cpIDs []string) error
```
> 现有 `TryOccupyInstanceSeat/ReleaseInstanceSeat/IsFrozen/GetRuntimeCoverage` 等在切换期保留，Phase 6 收口。
