# 远控/群控「从素材库选择文件」推送到云手机 — 设计

- 日期：2026-06-27
- 范围：在远控（单机）/群控（批量）的「上传文件」面板里，新增「从素材库选择」，把素材库中的私有文件推送到一台或多台云手机的 `/sdcard/Download`。
- 前置：素材库（私有桶 + `library.OpenFile`/`ListUsableFiles` 门面）已落地；远控/群控本地文件上传链路已存在。

## 1. 目标与非目标

### 目标
1. 用户在远控/群控的上传面板点击「从素材库选择」，弹出素材库浏览器（文件夹导航 + 类型筛选 + 关键字搜索 + 多选），选定后推送到目标手机。
2. 复用现有「主控 / 群控」范围切换：推送目标 = 当前 scope 决定的手机集合。
3. 私有桶字节**不经浏览器**：后端用 library 门面直读私有 S3 → 中台下发。
4. 与本地上传保持一致约束：一次最多 10 个文件、固定目录 `/sdcard/Download`。

### 非目标（YAGNI）
- 文件去重 / 断点续传。
- 自定义目标目录（沿用固定 `/sdcard/Download`）。
- 后端→前端的逐台实时上传百分比（见 §6 取舍）。

## 3. 架构与数据流

phone 模块经 library **公开门面**消费文件（Modulith：phone → library 单向；library 不反依赖 phone）。

```
[前端 LibraryPickerDialog] 选 file_ids（≤10）
        + 现有 scope → phone_ids（主控1台 / 群控N台）
   │
   ▼  POST /phone/files/push-from-library  { phone_ids, file_ids }
[phone handler] 校验 uid；逐个校验 phone_id 属主；校验 file_ids 1..10、phone_ids 非空
   │
   ▼
[phone service]
   1) 对每个 file_id：library.OpenFileContent(uid, fileID)
        → 内部：属主校验 + assertNotLocked + 仅 active → framework.S3Library.GetObject(s3Key)
        → 读出字节，组装 midplat.UploadFile{Name, Data}（**所有文件只下载一次**）
        → 任一失败（锁定/不存在/已删/非 active）：整请求失败，不下发任何手机
   2) 对每个 phone_id（有界并发=5）：ops.FileUpload(vmID, cpID, "/sdcard/Download", files)
        → 收集 per-phone {ok, error}
   │
   ▼  { results: [ { phone_id, ok, error? } ] }   // 允许部分成功
[前端] spinner → 复用 jobs 区展示 per-phone 成功/失败徽章
```

## 4. 后端设计

### 4.1 library 门面新增 `OpenFileContent`
文件：`backend/modules/library/library.go`（+ `internal` 实现）

```go
// FileContentRef 一个可用文件的内容流（调用方负责 Close Reader）。
type FileContentRef struct {
    FileID    uint
    Name      string
    MimeType  string
    SizeBytes int64
    Reader    io.ReadCloser
}

// OpenFileContent 取一个可用文件的字节流：属主校验 + 超额锁定校验 + 仅 active → S3 GetObject。
func OpenFileContent(userID int, fileID uint) (FileContentRef, error)
```

internal 实现（`internal/files.go` 或同处，与 `DownloadFile`/`OpenFile` 并列，复用同一套校验）：
1. `framework.S3Library == nil` → `errS3NotConfigured()`；
2. `assertNotLocked(userID)`（超额锁定拒绝）；
3. `repo.getFile(userID, fileID)`，`nil || Status != FileActive` → `apperr.NotFound`；
4. `rc, err := framework.S3Library.GetObject(ctx, f.S3Key)`；
5. 返回 `{FileID, Name, MimeType, SizeBytes, Reader: rc}`。

> 说明：复用 `OpenFile` 的全部校验，只把「presign 出 URL」换成「GetObject 出流」，避免后端再对 presigned URL 发一次 HTTP。

### 4.2 phone 模块：推送接口
路由（phone 模块路由注册处，紧邻现有 `/phone/:id/files/upload`）：

```
POST /phone/files/push-from-library
```

请求：
```json
{ "phone_ids": [12, 13], "file_ids": [101, 102] }
```

响应（`framework.OK`）：
```json
{ "code": 0, "message": "OK",
  "data": { "results": [
    { "phone_id": 12, "ok": true },
    { "phone_id": 13, "ok": false, "error": "下发失败" }
  ] } }
```

Handler（`op_api.go: PushFromLibrary`）：
- 取登录 `uid`（与现有鉴权一致）。
- 绑定 body；校验 `len(file_ids)` 在 `1..10`、`len(phone_ids) >= 1`，去重。
- 委托 `PhoneService.PushFromLibrary(uid, phoneIDs, fileIDs)`。

Service（`service.go: PushFromLibrary`）：
1. **逐个手机属主校验**：对每个 phone_id `resolveCp(uid, id)`，任一不属主 → 整请求 `apperr.Forbidden/NotFound`（前置失败，不下发）。
2. **下载一次**：遍历 `fileIDs` 调 `library.OpenFileContent(uid, fid)`；`io.ReadAll` 后 `Close`；组装 `[]midplat.UploadFile{Name, Data}`。任一失败 → 返回该错误（整请求失败，无副作用）。
   - 锁定/不存在/非 active 的错误直接透传（apperr）。
3. **有界并发下发**（worker=5）：对每个 phone 调 `s.ops.FileUpload(ctx, vmID, cpID, "/sdcard/Download", files)`，用 `opCtxUpload()` 超时；收集 `{phone_id, ok, error}`。
4. 返回 `[]PushResult`，允许部分成功。

> 内存：与现有本地上传一致（本地上传也把 multipart 全读进内存）。下载一次、多台复用，避免群控 N 台各拉一遍 S3。

### 4.3 Modulith 合规
- phone 仅 `import "manager-backend/modules/library"` 调公开门面；library 不感知 phone。
- 属主校验与超额锁定只在 library internal 一处；phone 侧只额外做「手机属主」校验。

## 6. 取舍：群控进度
后端「下载一次、同步下发」→ 推送请求阻塞到所有目标完成才返回，**群控无逐台实时百分比**，只有最终 per-phone 状态。
- 接受（本设计默认）：换取私有桶不暴露 + 大文件不过浏览器 + S3 只下载一次。
- 若日后需要逐台实时 %：改为前端逐台调用 `POST /phone/{id}/files/push-from-library`（每台各下载一次 S3），或引入 SSE/WS 推送进度。当前不做。

并发与超时：下发用有界并发（5）+ 每台 `opCtxUpload()` 超时；群控通常仅少量台数，不做长连接。

## 7. 错误处理
| 场景 | 行为 |
|---|---|
| 素材库超额锁定 | 下载阶段前置失败，整请求返回锁定错误，前端 toast `pushLocked` |
| 文件不存在/已删/非 active | 整请求前置失败，前端 toast `pushFail` |
| 某手机非属主 | 整请求前置失败（Forbidden/NotFound） |
| `file_ids` 超 10 / 为空 | 400 拒绝 |
| 部分手机下发失败 | 部分成功：该台标红，整体 toast `pushPartial` |
| S3 未配置 | `errS3NotConfigured` |
