# Gloryphone 测试文档总览

> 版本：2026-06-07 · 配套《[产品功能清单](../产品功能清单.md)》

本目录收录 Gloryphone 云手机平台**现阶段**的测试计划与测试用例。文档围绕《产品功能清单》中标注为 ✅ / 🟡 的**已实现功能**编写；🧪 原型与 ⛔ 占位功能仅做 UI 冒烟，不纳入功能验收。


## 用例编号规范

`TC-<域编号>-<序号>`，例如 `TC-02-007`。同一文档内序号连续；新增用例追加序号，不复用已废弃编号。

## 用例字段约定

| 字段 | 说明 |
| --- | --- |
| 用例ID | 全局唯一编号 |
| 标题 | 一句话描述被测点 |
| 类型 | 接口 / UI / 集成 / E2E / 安全 / 兼容 |
| 优先级 | P0（核心阻断）/ P1（重要）/ P2（一般）|
| 前置条件 | 数据、账号、状态准备 |
| 步骤 | 可复现的操作序列 |
| 预期结果 | 可判定的验收点 |
