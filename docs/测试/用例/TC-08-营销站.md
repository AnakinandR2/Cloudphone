## 备注
- 营销站当前内容（定价/博客/FAQ）多为 `useContent.ts` 与 i18n 中的静态数据，验收以"渲染正确、交互无错、SSR 一致"为准。
- SSR 登录态联动需在 nginx 统一域名下验证（同源 Cookie）。
