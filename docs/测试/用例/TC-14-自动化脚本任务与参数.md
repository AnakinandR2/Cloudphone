# TC-14 自动化脚本/任务/参数

> 覆盖：脚本管理（我的脚本/脚本商店/分类·搜索/增删改/参数 schema）、任务下发与状态机、计划任务（定时）、**参数注入（scriptParams 嵌套 console 格式）**、执行状态回写、任务日志、MCP 工具与端点鉴权。
> 关联接口：`/api/v1/automation/*`、`/api/v1/admin/automation/*`、`/api/v1/mcp/tools`、引擎根 `/api/mcp`；关联文档《产品功能清单》§3.9、§4.6，TC-05（应用库·中台链路）、TC-09（本域原型冒烟前身）。
> 背景：本域在 TC-09 仅做「原型冒烟」（无后端、静态数据）。automation / mcp 模块后端已建成（`backend/modules/automation`、`backend/modules/mcp`），本文档将其**升级为完整验收用例**。

## 脚本归属与参数真源模型

```mermaid
flowchart TB
    subgraph automation_scripts 表
      S1["store=false · user_id=owner\n我的脚本"]
      S2["store=true · user_id=0\n脚本商店"]
    end
    U[前台用户新建] --> S1
    ADM[admin script:manage 上传] --> S2
    S1 -->|GET /automation/scripts| MY1[my 我的脚本 Tab]
    S2 -->|GET /automation/scripts/store| MY2[my 脚本商店 Tab]
    S1 & S2 -->|启用者 GET /scripts/usable| RUN[下发任务选脚本]
    S1 -.唯一 mid_name 上传.- MID[(中台模板 scriptId)]
    S2 -.唯一 mid_name 上传.- MID
    RUN -->|scriptParams 嵌套 console 格式| MID
    MID -->|${key} 替换| CP[云手机执行]
```

> **参数真源约定**：脚本参数 schema 不单独存列，真源是 `lua_content` 顶部 `--[[ ... ]]` 注释（`deriveSchema` 现 parse），保存时校验。下发时 `serializeParams` 产出中台**嵌套 console 格式**的 `scriptParams`；扁平 `{key:value}` / `startParamMap` 均不触发 `${}` 替换（见备注引用的内存约定）。

## 关联/备注

- **环境**：需中台已配置（`MidplatBaseURL/AccessKey/SecretKey`），否则 `ops=nil`，脚本/任务/计划相关接口返回「云手机中台未配置」，且 `OnStart` 不启 `automation:task-sync` runner（TC-14-061）。MCP 端点鉴权复用开放 API 的 `gp_live_` 密钥体系（`openapi.Authenticate`）。
- **时间测法**：计划派生任务与状态刷新由 `automation:task-sync`（`PeriodicRunner`，每分钟一轮、90s 超时）驱动，手测需等一轮或直接触发 `Service.syncTasks(ctx)`；`beijingNow` 以 UTC+8 生成中台无时区时间串。
