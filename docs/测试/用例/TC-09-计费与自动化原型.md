> **说明**：这些功能**无后端**，使用页面内静态数据。本组仅做 **UI 冒烟**，验证"能渲染、交互不报错、不误导为真实数据"，不做功能验收。
> 关联文档《产品功能清单》§3.9、§3.10、§4.5、§4.6。

## 验收原则

```mermaid
flowchart LR
    A[原型页面] --> B{能正常渲染?}
    B -->|否| F[记缺陷]
    B -->|是| C{交互无 JS 报错?}
    C -->|否| F
    C -->|是| D{无对后端的真实写操作?}
    D -->|否| F
    D -->|是| P[通过冒烟]
```
