9 · 内容模型 (Content model)

全部文案在 composables/useGp.ts 的 GP_CONTENT（{ zh, en }）中。新增/修改文案需同时改两种语言并保持结构一致（组件按下标取值）。

<script setup lang="ts">
const { t } = useGp()        // t 是当前语言内容对象的 computed ref
</script>
<template>{{ t.hero.title1 }}</template>   // 模板自动解包 ref
// <script> 内用 t.value.hero.title1

11 · Agent 约定 (Conventions)

  1. 复用类名词汇（见 §8），不要用原始 Tailwind 工具类重新给区块上样式。
  2. 颜色始终用 rgb(var(--token) / a)（三元组）或 var(--accent-color)（hex），绝不硬编码品牌色。
  3. 暗色模式不要硬编码浅色值，依赖会随 .dark 翻转的 --bg/--fg/…。
  4. 文案来自 useGp()（GP_CONTENT），两种语言、结构一致。
  5. 图标只用 GpIcon / GpPartnerMark。
  6. 新区块：建 components/sections/XxxSection.vue，外层 <section class="section" id="xxx">，文案取自 useGp，再加入 pages/index.vue。滚动揭示对已知选择器自动生效，否则扩展 plugins/reveal.client.ts。
  7. 静态资源放 public/images/，以 /images/<file> 引用。
  8. 验证：pnpm build 后 node .output/server/index.mjs 看 /。
